# assets/

给面板和 README 用的静态图片。运行时只读，不接受上传。

| 文件 | 用在哪 | 要求 |
| --- | --- | --- |
| `payme-hk.png` | ☕ 弹窗的「🇭🇰 香港」栏 | 600×600 正方形收款码（AlipayHK / PayMe / FPS） |
| `payme.png` | ☕ 弹窗的「🇨🇳 内地」栏 | 600×600 微信收款码 || `screenshot-*.png` | README | 建议宽度 1280，别超过 1 MB，否则仓库变大 |

## 换收款码

直接用同名文件覆盖 `assets/payme.png`，**不用改任何代码**。

面板通过 `GET /api/study-coach/asset?name=payme.png` 读这张图：

- 文件不在 → 返回 404，面板把 `<img>` 藏掉，只留文字说明，不会显示破图
- 文件名只认 `A-Za-z0-9._-` + 图片扩展名，`../` 一律拒绝

现在这张是占位图（灰框 + 说明文字），发布前记得换掉。
